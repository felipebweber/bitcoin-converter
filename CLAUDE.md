## Usage

These skills are automatically available when working with Swift code in this project. They provide context-aware assistance for:

- Code generation and completion
- Best practice recommendations
- Architecture guidance
- Performance optimization
- Testing strategies
- And much more!

## Installation

The Swift skills are configured through the local `.claude/settings.local.json` file and reference the marketplace in `.claude/.claude-plugin/marketplace.json`.
